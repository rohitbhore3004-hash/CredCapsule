Rebuild CredCapsule v4 from scratch. Everything needed is in this file.

PROJECT: credcapsule_single.py — single-file Python credential vault.
Only external dep: `cryptography` library. Works on Linux, macOS, Windows.
No database, no SQLite. Custom binary .ccv file format.

━━━ CRYPTO STACK (implement everything, nothing omitted) ━━━
- X25519 / Curve25519 key exchange
- X3DH (Extended Triple Diffie-Hellman) — single-party session bootstrap
  with 10 one-time prekeys; DH1=IK×SPK, DH2=EK×IK, DH3=EK×SPK, DH4=EK×OTK
  HKDF("X3DHv4_Root", ikm=dh1‖dh2‖dh3‖dh4, salt=zero32) → root_secret
- Double Ratchet — DH ratchet step on EVERY vault.unlock()
  Self-ratchet: DH(dh_priv, prev_pub) → dh_out
  new_rk  = HKDF(rk ‖ dh_out, "RKUpd_v4")
  new_ck  = HKDF(rk ‖ dh_out, "CKUpd_v4")
  msg_key = HMAC-SHA256(new_ck, b"\x01")
  Then rotate: prev_pub = old_dh_pub, generate new dh keypair
- AES-256-GCM — all data at rest; per-credential isolated keys
- HMAC-SHA256 — symmetric ratchet chain + file integrity checksum
- HKDF-SHA256 — all key derivation, domain-separated info strings
- scrypt(N=131072, r=8, p=1) — password → 32-byte master key (~1s, ~128MB)
- BLAKE2b keyed hash — label_hash = blake2b(label, key=salt[:32], digest_size=32)
  Labels NEVER stored in plaintext. label_hash stored instead.

━━━ BINARY FILE FORMAT (.ccv) ━━━
Header (86 bytes, unencrypted):
  [0:10]   Magic: b'CREDCAPS\x04\x00'
  [10:42]  Salt: 32 random bytes (scrypt + BLAKE2b key)
  [42:54]  KDF params: struct.pack(">III", 131072, 8, 1)
  [54:86]  File HMAC: HMAC-SHA256(file_key, body)
           file_key = HKDF(master_key, "FileIntegrity_v4", salt=vault_salt)

Body (after header) — big-endian TLV sections:
  Each section: [4-byte tag][4-byte length big-endian][data]
  Order: VERI · RATC · X3DH · KDFP · ENTR · AUDT

Section contents:
  VERI: AES-GCM(VerifyKey_v4, random32, aad=b"VERI")     ← password check
  RATC: AES-GCM(RatchetKey_v4, ratchet_state, aad=b"RATC")
  X3DH: AES-GCM(X3DHKey_v4, x3dh_bundle, aad=b"X3DH")
  KDFP: struct.pack(">III", N, r, p)                      ← plaintext params
  ENTR: concatenated individual credential blobs (NOT one big encrypted blob)
        each entry = [32B label_hash][4B length big-endian][AES-GCM blob]
        AES-GCM blob = nonce(12) + ciphertext + tag(16)
        entry key = HKDF(master_key, b"EntryKey_v4" + label_hash, salt=vault_salt)
        AES-GCM AAD = label_hash (prevents swap attacks)
  AUDT: AES-GCM(AuditKey_v4, json_bytes, aad=b"AUDT")

Key derivation info strings (HKDF info param, all UTF-8 bytes):
  "VerifyKey_v4", "RatchetKey_v4", "X3DHKey_v4", "AuditKey_v4"
  "FileIntegrity_v4", "EntryKey_v4" (prepend label_hash as suffix)
  Ratchet init: "RatchetRoot_v4", "RatchetChain_v4"
  Ratchet step: "RKUpd_v4", "CKUpd_v4"
  X3DH: "X3DHv4_Root"

Ratchet state binary (160 bytes + 4):
  rk(32) + ck(32) + dh_prv(32) + dh_pub(32) + prev_pub(32) + n(4 big-endian)

X3DH bundle binary:
  ik_priv(32) + ik_pub(32) + spk_priv(32) + spk_pub(32)
  + num_otk(2 big-endian) + [priv(32)+pub(32)] * num_otk

Atomic writes: write to .ccv.tmp then os.replace() → safe on POSIX + NTFS
File chmod 440 (POSIX) / S_IREAD (Windows) after every write
File HMAC verified BEFORE any decryption attempt
Empty vault ~1.8KB; each credential ~310 bytes

━━━ VAULT CLASS PUBLIC API ━━━
Vault.create(path, password, timeout=300)  → Vault (already unlocked)
Vault.open(path, timeout=300)              → Vault (locked, call .unlock() next)
vault.unlock(password)         advances Double Ratchet DH step, saves new state
vault.lock()                   saves state then zeros all key material via ctypes.memset
vault.set_credential(cred)     stores any Credential type
vault.get_credential(label)    → typed Credential object
vault.get(label)               → primary secret string
vault.get_username(label)      → str (LoginCredential only)
vault.get_password(label)      → str (LoginCredential only)
vault.get_credential_secure(label) → context manager, zeros string fields on exit
vault.has(label)               → bool
vault.delete(label)
vault.list()                   → sorted list of label strings
vault.count()                  → int
vault.info()                   → dict (no unlock needed)
vault.audit_log()              → list of {"ts": float, "ev": str}
vault.rotate_password(old, new) re-derives salt, re-encrypts all entries
vault.destroy(password)        verifies password, wipes keys, unlinks file
vault.backup()                 → raw bytes of vault file
Context manager: auto-locks on __exit__

━━━ RETRY LIMITING ━━━
fail_count tracks consecutive wrong-password attempts on an instance
Before each unlock attempt: check table, sleep if threshold crossed
{3: 5s, 5: 30s, 7: 120s, 10: 600s, 15: 3600s}
At 20 failures → raise RetryLimitError (no more attempts)
Success resets fail_count to 0

━━━ SECURE MEMORY ━━━
All key material held in bytearray, NOT bytes (so ctypes.memset works)
Zero pattern: ctypes.memset((ctypes.c_char * len(buf)).from_buffer(buf), 0, len(buf))
Zeroed on lock(): mk, fk, rk, ck, dh_prv fields of ratchet state
rotate_password: zero old mk and fk before replacing with new

━━━ SECURITY PROPERTIES ━━━
- Label names never stored in plaintext (BLAKE2b keyed hash stored)
- Per-credential key isolation: HKDF(mk, "EntryKey_v4" + label_hash, salt)
- AES-GCM AAD = label_hash → ciphertext bound to entry identity
- File HMAC covers entire body → tamper-evident before any decryption
- Double Ratchet: compromise of current ratchet state reveals nothing about past sessions
- X3DH bootstrap: forward secrecy from first unlock
- scrypt N=2^17: ~1 second / ~128MB RAM per attempt on commodity hardware
- ctypes.memset: key material zeroed in-process before GC
- os.chmod only: no subprocess calls for permissions
- Atomic writes: power-safe, no partial-write corruption
- Retry backoff: exponential delays up to 1hr, hard cap at 20 attempts

━━━ EXACT SIZES FOR VERIFICATION ━━━
